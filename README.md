# 水果忍者 · 元素道场

基于 **Three.js** 的 3D 切水果游戏。所有水果模型、贴图、音效、背景音乐全部由代码程序化生成，**不依赖任何外部素材**。

## 怎么玩

**直接双击 `index.html` 即可游玩**（已打包好的 `dist/game.js`，无需服务器）。

开发模式：

```bash
npm install
npm run dev      # http://localhost:5173，监听 src/ 变化即时重新打包
npm run build    # 生产打包 → dist/game.js（index.html 双击可玩）
npm test         # 切割器单元测试（体积守恒 / 网格封闭 / 二次切割 / 凹形截面）
```

### 操作

| 操作 | 说明 |
| --- | --- |
| 按住鼠标 / 手指划过水果 | 挥刀切割（划得越快越锋利，速度太慢切不开） |
| `空格`（按住）/ 鼠标右键 / 屏幕「眼」按钮 | **心眼**：子弹时间 |
| `Esc` / `P` | 暂停 |
| `M` | 静音 |
| 菜单里 `1` `2` `3` | 选择模式 |
| 「悬停切割」 | 不用按键，鼠标划过即可切（菜单里开关） |

### 模式

- **经典**：3 条命，漏掉水果或斩到炸弹掉命，无尽挑战
- **限时**：60 秒，斩到炸弹 −5 秒
- **禅意**：90 秒，没有炸弹，专心连斩

## 玩法特色

1. **真·3D 网格切割** —— 不是贴图切换。刀锋划过时，水果的三角网格被平面真实裁剪，沿切口重建截面并贴上程序化绘制的果肉（西瓜籽、橙子瓣、猕猴桃籽圈、苹果五角核、杨桃的星形截面……）。两半会朝镜头翻开，露出各自真实的截面。
2. **完美斩** —— 刀过果心（切口近乎对半）得分翻倍，触发顿帧与金色光效。
3. **二次斩** —— 飞出的半块还能再劈一刀，碎成四块，额外得分。
4. **连斩 & 连击** —— 一刀连斩 3 个以上触发连斩加分；连续不失误累积连击，得分倍率最高 ×5。
5. **四种元素果**（带光环与粒子）：
   - 🐉 **火龙果 · 烈焰斩**：爆炸波及周围水果，刀刃燃烧，每次斩击引燃邻近水果，还能**净化炸弹**
   - 🍐 **雪梨 · 冰封时刻**：时间几乎静止，得分翻倍
   - ⭐ **杨桃 · 雷霆之刃**：每次斩击引发闪电，连锁劈向附近水果
   - 🍎 **金苹果 · 黄金时刻**：得分 ×3，水果狂潮，炸弹消失
6. **心眼** —— 积攒能量后按住进入子弹时间，看清 3D 切面，从容斩击。
7. **悬赏令** —— 随机任务（斩指定水果 / 一刀连斩 / 完美斩 / 二次斩），完成得奖励。
8. **西瓜大王** —— 定时来袭的巨型西瓜，可层层劈成 8 块。
9. **段位** —— 白带 → 黄 → 橙 → 绿 → 蓝 → 紫 → 棕 → 红 → 黑带 → 宗师。
10. **菜单也能切**：主菜单里的三个模式水果，斩开哪个就进入哪个模式。

```
  main.js                     入口：加载 → 生成图标 → 游戏循环 + 自适应画质
  game.js                     游戏规则：状态机 / 得分 / 元素技能 / 心眼 / 炸弹 / 菜单
  world.js                    实体物理、真实切割、碎块"翻开截面"的旋转
  slicer.js                   ★ 网格切割器：平面裁剪 + 切口回路重建 + 截面封盖
  blade.js                    指针输入（多点触控）→ 刀痕线段 + 发光丝带轨迹
  director.js                 波次导演：难度曲线、出场图案、炸弹/元素果/Boss 调度
  bounty.js                   悬赏令
  ui.js / icons.js            HUD、菜单、结算；图标由真实 3D 模型离屏渲染
  audio.js                    WebAudio 合成音效 + 和风生成式背景音乐
  stage.js                    渲染器、灯光、泛光/调色后期、坐标换算
  models/
    shapes.js                 参数曲面建模（θ,φ→形状）+ 叶/茎/冠/鳞片/冰晶附件
    skins.js / caps.js        表皮贴图 / 截面贴图（逐像素噪声 + 2D 绘制）
    props.js / fruits.js      配件贴图、水果资产注册表（材质、定义）
  fx/
    particles.js              丝带、发光粒子、果汁水滴、冲击环/斩痕、闪电
    background.js             木纹墙、灯笼、樱花、果汁溅射层

```

## 技术要点

- **切割算法**（`src/slicer.js`）：对非索引三角网格逐三角形按平面裁剪并插值 position/normal/uv；切口线段按 exit→entry 收集，合并端点后追踪成回路；星形回路用「从质心扇形展开 + UV 映射到单位圆」，让截面图案自动贴合真实轮廓（星形/椭圆/五边形都能对上），凹形（香蕉纵切）回退到耳切法。半块可以继续被切。
- **建模**：主体是参数曲面 `shape(θ, φ)`，自动纠正朝向并解析求法线；极点与接缝顶点严格重合，保证网格封闭。
- **画面**：ACES 色调映射 + 环境反射 + 阴影 + 泛光；心眼/冰封/黄金时刻有各自的调色。
- **自适应画质**：帧率持续偏低时依次降分辨率 → 关阴影 → 关泛光。

## 调试参数

- `?view=whole` / `?view=cut`：模型查看器（`&only=apple,kiwi` `&scale=2` `&tilt=0.3`）
- `?bot=1`：自动游玩机器人（用于压力测试）
- `?q=low`：低画质
